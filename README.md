# Task 12: Registration Form with External CSS and JavaScript

This repository demonstrates how to create a simple registration form and how to separate inline CSS and JavaScript into external files for better code organization.

## Contents

-   **`task12/`**: This directory contains the final version of the registration form with external CSS and JavaScript.
    -   `index.html`: The main registration form.
    -   `style.css`: The external stylesheet for the form.
    -   `script.js`: The external JavaScript for password validation.
    -   `submit.html`: The page displayed after successful registration.

-   **`task12/html_with_inline_css/`**: This directory contains the initial version of the registration form with inline CSS and JavaScript.
    -   `index.html`: The registration form with CSS and JavaScript embedded directly in the HTML.
    -   `submit.html`: The success page.

-   **`task12/seperate_css.txt`**: A text file with instructions on how to move inline CSS to an external stylesheet.
-   **`task12/seperate_js.txt`**: A text file with instructions on how to move inline JavaScript to an external script file.

## How to Use

1.  **Initial Version**: Open `task12/html_with_inline_css/index.html` in a web browser to see the form with inline styling and scripting.
2.  **Final Version**: Open `task12/index.html` in a web browser to see the form with external CSS and JavaScript.
3.  **Instructions**: The `.txt` files provide instructions on how to refactor the code from the initial version to the final version.
